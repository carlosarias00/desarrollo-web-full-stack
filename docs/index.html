Bienvenido a mi proyecto de Desarrollo Web Full Stack

En este proyecto se presentan los conocimientos y trabajos desarrollados durante el curso de Desarrollo Web Full Stack.

Actualmente estamos trabajando en la creación de páginas web utilizando HTML5, CSS3 y JavaScript.

Conocer el proyecto

¿Qué es el desarrollo web?

El desarrollo web es el proceso de crear páginas y aplicaciones que funcionan mediante un navegador web. Para ello se utilizan diferentes tecnologías que permiten estructurar, diseñar y agregar interacción a los sitios web.

Durante el curso se estudian los principales fundamentos del desarrollo Front-End, comenzando por la estructura de una página y posteriormente incorporando estilos y funcionalidades.

Tecnologías principales

HTML5

HTML5 permite crear la estructura y organizar el contenido de una página web mediante elementos y etiquetas semánticas.

CSS3

CSS3 permite aplicar estilos, colores, tamaños, posiciones y diferentes diseños para mejorar la presentación de una página web.

JavaScript

JavaScript permite agregar interacción y comportamiento dinámico a las páginas web.

HTML5

Maquetación web

HTML5 permite organizar correctamente los elementos que forman parte de una página web.

En este proyecto se utilizan diferentes elementos semánticos para estructurar el contenido.

  • Header: encabezado de la página.
  • Nav: menú de navegación.
  • Main: contenido principal.
  • Section: organiza el contenido por temas.
  • Article: representa contenido independiente.
  • Aside: contiene información complementaria.
  • Footer: pie de página.

Avance del curso

Semana 1 - Introducción

Introducción al desarrollo web, conceptos fundamentales y funcionamiento de las aplicaciones web.

  • Desarrollo web
  • Front-End y Back-End
  • Full Stack
  • Aplicaciones web

Semana 2 - HTML5 y CSS3

Creación y estructuración de páginas web utilizando HTML5, junto con la aplicación de estilos mediante CSS3.

  • Estructura HTML5
  • Etiquetas semánticas
  • Maquetación web
  • Estilos CSS3

Semana 3 - Portafolio

Desarrollo de un portafolio web personal aplicando los conocimientos adquiridos de HTML5 y CSS3.

  • Diseño del portafolio
  • Organización de contenido
  • Aplicación de estilos
  • Publicación en GitHub Pages

Semana 4 - Permanencia 01

Desarrollo de la actividad de permanencia utilizando JavaScript para incorporar funcionalidad e interacción a la página web.

  • Fundamentos de JavaScript
  • Variables y datos
  • Funciones
  • Interacción con la página

Integración del proyecto

El proyecto integra las diferentes tecnologías estudiadas durante el curso. HTML5 se encarga de la estructura, CSS3 de la presentación visual y JavaScript de la interacción.

Además, se incorpora un portafolio personal como parte del desarrollo práctico realizado durante el curso.
